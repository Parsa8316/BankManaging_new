# مدیریت بانک (نسخه مدرن اندروید)

نسخه بازنویسی و ارتقایافته اپلیکیشن **مدیریت بانک** با **Kotlin و Jetpack Compose (Material 3)** برای مدیریت هوشمند، سریع و کاملاً محلی پیامک‌های بانکی.

## امکانات و بهبودها

- **رابط کاربری مدرن و فارسی (RTL)** با فونت **Vazirmatn**، کارت خلاصه مالی با نمودار نسبت واریز به برداشت، و پشتیبانی از تم روشن، تیره و خودکار سیستم.
- **الگوهای پیامکی سفارشی (Custom SMS Patterns)** در بخش تنظیمات:
  - پشتیبانی آماده از **بلوبانک، بانک ملت، بانک ملی، بانک سامان/پاسارگاد** و الگوی هوشمند عمومی بانک‌های ایران.
  - امکان تعریف الگوی اختصاصی جدید یا ویرایش و کپی الگوهای موجود با تعیین فرستنده، کلمات شناسه، واحد پول (ریال/تومان)، کلمات کلیدی واریز/برداشت/رمز پویا و روش استخراج مبلغ و موجودی (هوشمند با کلمه کلیدی، شماره خط، یا عبارت منظم Regex).
  - **آزمایش زنده الگو (Live Pattern Tester)** برای بررسی فوری استخراج داده‌ها روی متن واقعی پیامک.
- **فیلتر پیشرفته با تقویم شمسی واقعی**: فیلتر بر اساس نوع تراکنش (دریافتی، خرجی، سایر)، عنوان عملیات، بانک، بازه مبلغ، بازه موجودی، بازه تاریخ شمسی و جستجو در متن.
- **رفع خطاهای نسخه قبلی**: رفع کرش‌های نبود دسترسی پیامک، نشت Cursor، خطای فیلدهای خالی در فیلتر، خطای تبدیل اعداد فارسی/عربی، خطای `IndexOutOfRange` در پیامک‌های کوتاه و خطای تشخیص فرستنده تکراری.
